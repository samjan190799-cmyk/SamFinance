# Hashiv — личные финансы для iOS

Приложение для учёта доходов и расходов (в App Store и TestFlight называется **Hashiv**, внутри проекта оно по-прежнему `SamFinance`). Основная валюта — армянский драм, есть рубль, доллар и евро. Интерфейс на русском, английском и армянском.

## Возможности

* **Обзор:** баланс, траты за неделю и 30 дней, главные категории, последние операции.
* **Новая операция:** крупная цифровая клавиатура, категории, распознавание банковской СМС из буфера обмена, пакетный импорт истории СМС.
* **ИИ-чат:** скриншоты и тексты СМС превращаются в операции (разбор на телефоне), вопросы о деньгах. По желанию подключается Claude, ChatGPT или Gemini по ключу пользователя; перед первой отправкой данных приложение спрашивает разрешение. Без ключа отвечает локальный помощник.
* **Карты и копилки:** карусель карт (нажатие переворачивает карту), заморозка, цели накопления. Полный номер карты хранится в Keychain, CVV не сохраняется.
* **Долги и кредиты:** смахивание строки — погашен или удалить, напоминания о сроках.
* **Отчёт:** график по дням и доли категорий за день, неделю, месяц или всё время; экспорт в CSV.
* **Автоматизация:** фоновая запись СМС и подсказка после оплаты Apple Pay через Быстрые команды (App Intents).

## Технологии

* iOS 17+, только iPhone
* Swift 6 со строгой проверкой многопоточности (`SWIFT_STRICT_CONCURRENCY: complete`), SwiftUI, `@Observable`
* XcodeGen: проект описывается в `project.yml`, `.xcodeproj` в репозитории не хранится
* Данные: JSON-файлы в песочнице приложения, секреты (номера карт, ключи ИИ) в Keychain

## Структура

```text
├── Sources/
│   ├── App/        точка входа
│   ├── Helpers/    тема, движение, локализация, разбор СМС, ключи, команды Siri
│   ├── Models/     транзакции, карты, долги, цели, категории
│   ├── Services/   данные, автоматизация, ИИ-клиенты, уведомления, курсы валют
│   └── Views/      экраны SwiftUI
├── Resources/      иконка, манифест приватности, переводы (ru, en, hy .lproj)
├── Tests/          модульные тесты (XCTest)
└── project.yml     описание проекта для XcodeGen
```

## Сборка

```bash
brew install xcodegen
xcodegen generate
open SamFinance.xcodeproj
```

## Языки

Строки лежат в `Resources/{ru,en,hy}.lproj/Localizable.strings`. **Ключ — русский текст**, поэтому для русского языка перевод не нужен (в `ru.lproj` остались только короткие ключи прежнего словаря). Чтобы добавить строку:

1. Пишите её в коде по-русски: `Text("Новая строка")` или `String(localized: "Новая строка \(name)")`.
2. Добавьте перевод в `en.lproj` и `hy.lproj` под тем же ключом; подстановки `%@` и `%lld` в ключе и переводе должны совпадать.
3. `LocalizationTests` проверит, что наборы ключей и подстановки согласованы.

Язык выбирает система. iOS не предлагает армянский в списке языков телефона, поэтому в Настройках приложения язык сохраняется в `AppleLanguages` приложения и применяется после перезапуска. Встроенные категории переводятся через `Category.displayName`, а в данных хранятся под русскими названиями.

## Тесты

```bash
xcodegen generate
xcodebuild test -project SamFinance.xcodeproj -scheme SamFinanceTests \
  -destination 'platform=iOS Simulator,name=iPhone 16'
```

В GitHub Actions тесты запускает workflow «Unit Tests» на каждом pull request.

## Сборки и TestFlight

* «Build SamFinance iOS IPA» — сборка без подписи на pull request в `main`.
* «Deploy SamFinance to TestFlight» — подпись и загрузка в TestFlight вручную (`workflow_dispatch`) или по тегу `v*`; номер сборки равен номеру запуска.
