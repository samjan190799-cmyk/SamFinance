# Hashiv — личные финансы для iOS

Приложение для учёта доходов и расходов (в App Store и TestFlight называется **Hashiv**, внутри проекта оно по-прежнему `SamFinance`). Основная валюта — армянский драм, есть рубль, доллар и евро. Интерфейс на русском, английском и армянском.

## Возможности

* **Обзор:** баланс, траты за неделю и 30 дней, главные категории, последние операции.
* **Новая операция:** крупная цифровая клавиатура, категории, распознавание банковской СМС из буфера обмена, пакетный импорт истории СМС.
* **ИИ-чат:** скриншоты и тексты СМС превращаются в операции (разбор на телефоне), вопросы о деньгах. Работает через облачный ИИ (Claude, ChatGPT или Gemini) по ключу, который встраивается в сборку из секретов GitHub; перед первой отправкой данных приложение спрашивает разрешение, отозвать его можно переключателем в Настройках. Облачный ИИ отвечает и по всей истории («сколько ушло на продукты в сентябре», «самые крупные покупки за год»): он просит итоги за период, категорию, магазин или карту, приложение считает их на телефоне (`DataQuery`), и до двух раз за вопрос присылает результаты, а в облако уходят только итоги. Переписка (последние 200 сообщений, только тексты) хранится на устройстве и переживает перезапуск; «Начать заново» и сброс данных её стирают. Без ключа отвечает локальный помощник.
* **Реклама:** на каждой из пяти вкладок свой баннер Яндекс Рекламы внутри прокрутки, между первым и вторым блоком экрана (на «Обзоре» между картой баланса и кнопками); при заходе на вкладку он запрашивает рекламу заново. Баннер занимает отдельную полосу в потоке экрана и не закрывает кнопки и поля ввода. Идентификатор рекламного блока задаёт сборка (секрет `YANDEX_ADS_BANNER_ID`), без него рекламы нет. Перед первой рекламой показывается запрос ATT; финансовые данные в рекламу не передаются.
* **Карты и копилки:** карусель карт (нажатие переворачивает карту), заморозка, закрепление карты первой (булавка или долгое нажатие), цели накопления; под каруселью цели той карты, что в центре. Полный номер карты хранится в Keychain, CVV не сохраняется.
* **Долги и кредиты:** смахивание строки — погашен или удалить, напоминания о сроках.
* **Подписки:** четвёртая вкладка экрана «Долги» (рядом с «Мне должны», «Я должен» и «Платежи»). Подписка — это регулярное списание, которое происходит само: название, сумма в своей валюте (драм, рубль, доллар, евро), период (неделя, месяц, год, можно «каждые N»), дата списания, вид со значком, карта списания по желанию и заметка. Сверху итоги «в месяц» и «в год» по активным подпискам (каждая сумма переводится в основную валюту по курсу; неделя считается как 52 в году), ниже список по ближайшему списанию. Ближайшее списание приложение находит само по первой дате и периоду, считая от первой даты, поэтому подписка «31-го числа» не застревает на 28-м. Подписку можно поставить на паузу или убрать в архив (смахивание вправо, смахивание влево, меню по долгому нажатию, поле «Статус» в форме): на паузе и в архиве она не входит в итоги и не напоминает. Напоминание о списании приходит за выбранное число дней (по умолчанию за день) в общее время напоминаний; включается и выключается переключателем «Подписки» в настройках напоминаний, нажатие на него открывает вкладку «Подписки». Данные лежат в `subscriptions.json` рядом с остальными файлами; у тех, кто обновился, файла нет, и список просто пуст. Карта списания только подписывает подписку: операции и баланс карты она не меняет. Вид платежа «Подписки» на вкладке «Платежи» остался для прежних записей.
* **Отчёт:** график по дням и доли категорий за день, неделю, месяц или всё время; экспорт в CSV.
* **Автоматизация:** фоновая запись СМС и подсказка после оплаты Apple Pay через Быстрые команды (App Intents).

## Технологии

* iOS 17+, только iPhone
* Swift 6 со строгой проверкой многопоточности (`SWIFT_STRICT_CONCURRENCY: complete`), SwiftUI, `@Observable`
* XcodeGen: проект описывается в `project.yml`, `.xcodeproj` в репозитории не хранится
* Данные: JSON-файлы в песочнице приложения, секреты (полные номера карт) в Keychain

## Структура

```text
├── Sources/
│   ├── App/        точка входа
│   ├── Helpers/    тема, движение, локализация, разбор СМС, ключи, команды Siri

│   ├── Services/   данные, автоматизация, ИИ-клиенты, уведомления, курсы валют

├── Resources/      иконка, манифест приватности, переводы (ru, en, hy .lproj)

```

```bash

open SamFinance.xcodeproj
```

## Языки

Строки лежат в `Resources/{ru,en,hy}.lproj/Localizable.strings`. **Ключ — русский текст**, поэтому для русского языка перевод не нужен (в `ru.lproj` остались только короткие ключи прежнего словаря). Чтобы добавить строку:

1. Пишите её в коде по-русски: `Text("Новая строка")` или `String(localized: "Новая строка \(name)")`.
2. Добавьте перевод в `en.lproj` и `hy.lproj` под тем же ключом; подстановки `%@` и `%lld` в ключе и переводе должны совпадать.
3. `LocalizationTests` проверит, что наборы ключей и подстановки согласованы.

Язык выбирает система. iOS не предлагает армянский в списке языков телефона, поэтому в Настройках приложения язык сохраняется в `AppleLanguages` приложения и применяется после перезапуска. Встроенные категории переводятся через `Category.displayName`, а в данных хранятся под русскими названиями.

## Тесты

```bash
xcodegen generate
xcodebuild test -project SamFinance.xcodeproj -scheme SamFinanceTests \
  -destination 'platform=iOS Simulator,name=iPhone 16'
```

В GitHub Actions тесты запускает workflow «Unit Tests» на каждом pull request.

## Сборки и TestFlight

* «Build SamFinance iOS IPA» — сборка без подписи на pull request в `main`.
* «Deploy SamFinance to TestFlight» — подпись и загрузка в TestFlight вручную (`workflow_dispatch`) или по тегу `v*`; номер сборки равен номеру запуска.
* Ключ ИИ-чата задаёт сборка, а не пользователь. Секреты GitHub (Settings → Secrets and variables → Actions): `AI_API_KEY` (ключ API; без него чат отвечает локальным помощником), необязательные `AI_PROVIDER` (`gemini`, `claude` или `openai`; по умолчанию `gemini`) и `AI_MODEL` (по умолчанию стандартная модель сервиса). Шаг «Inject AI Settings» кладёт их в Info.plist после `xcodegen generate`. Секрет `YANDEX_ADS_BANNER_ID` (боевой блок вида `R-M-…-…` из партнёрского интерфейса Яндекса или демо-блок `demo-banner-yandex` для проверки) кладёт шаг «Inject Ads Settings»; без него в сборке нет рекламы. Боевой блок не проверяйте нажатиями на собственную рекламу. Ключ попадает в приложение и виден тому, кто распакует IPA, поэтому его нужно ограничить на стороне сервиса: для Gemini в Google Cloud Console (ограничение по приложению iOS с идентификатором `com.samvel.samfinance.V7J345DY58`, приложение шлёт заголовок `X-Ios-Bundle-Identifier`) и с суточной квотой или бюджетом.
