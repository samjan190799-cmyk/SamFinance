# Сборка ролика для App Store (App Preview)

Ролик собирается кодом из записи экрана симулятора. Показаны только настоящие экраны приложения, движется лишь графика поверх.

## Как это работает

1. Сборка в режиме ролика (`-ScreenshotTour`, только DEBUG на симуляторе) сама проигрывает сценарий из 7 сцен. Подписей в записи нет: в полосе над экраном стоит серая метка, её длина равна номеру сцены (`Sources/Helpers/ScreenshotMode.swift`).
2. `scenes.py` читает запись: отбрасывает кадры с временем «назад», по метке находит границы сцен (если метки нет, ищет по старой лаймовой плашке), сокращает паузы, когда экран стоит неподвижно, и раскладывает кадры по времени ролика.
3. `overlay.py` рисует поверх: анимированную подпись (плашка пружинит, слова появляются по очереди), касания вкладок, полосу прогресса из семи отрезков, плавное начало и конец. Полоса подписи в записи закрашивается, поэтому метка в кадр не попадает.
4. `music.py` синтезирует короткую музыку и звуки касаний и достижения цели. Чужих записей нет, прав третьих лиц тоже.
5. `compose.py` собирает всё: кадры записи плавно смешиваются при небольшом движении, затем идёт кодирование в H.264 886x1920, 30 кадров/с, AAC.

Тексты подписей берутся из `Resources/<язык>.lproj/Localizable.strings`, русский текст служит ключом.

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install pillow numpy
.venv/bin/python -m unittest discover -s Tools/AppPreview
.venv/bin/python Tools/AppPreview/compose.py --ffmpeg ffmpeg --raw raw/ru.mp4 --lang ru \
  --resources Resources --out preview/hashiv_preview_ru.mp4
```

Ключ `--no-music` собирает ролик без музыки, `--frames-dir папка` сохраняет контрольные кадры.

## Правила Apple, которые учтены

- Ролик 15-30 секунд, 886x1920, H.264. Экраны только из приложения; транзитная графика допустима (касания, подписи, затухание).
- Приближение записи (зум) Apple не рекомендует, поэтому его нет.
- Без цен и дат в подписях.

Шрифты Noto Sans и Noto Sans Armenian (лицензия SIL OFL 1.1, текст в `fonts/OFL.txt`).
