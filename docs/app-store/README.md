# Hashiv: подготовка к App Store

Здесь лежит всё, что нужно для карточки приложения в App Store Connect, кроме скриншотов и кода.

| Файл | Для чего |
| --- | --- |
| `../privacy/index.html` | страница политики конфиденциальности на русском и английском (её адрес идёт в Privacy Policy URL) |
| `app-privacy.md` | ответы для анкеты App Privacy, возрастной рейтинг, шифрование |
| `review-notes.md` | текст для поля Notes в App Review Information |
| `../../Resources/Legal/PrivacyPolicy.ru.md`, `.en.md` | источник политики: те же файлы показываются в приложении |

## Публикация политики

Приложению нужна рабочая ссылка на политику в поле **Privacy Policy URL** (App Store Connect → App Information). Репозиторий публичный, поэтому проще всего GitHub Pages:

1. На GitHub: репозиторий → **Settings → Pages**.
2. Source: **Deploy from a branch**, ветка **main**, папка **/docs**. Сохранить.
3. Через минуту страница будет по адресу `https://samjan190799-cmyk.github.io/SamFinance/privacy/`. Откройте её и проверьте оба языка.
4. Этот адрес вставьте в Privacy Policy URL. Для Support URL нужна страница, где можно с вами связаться (почта или форма).

Страница появится на `main` только после слияния этой ветки. Любой другой хостинг тоже подойдёт: нужно выложить один файл `docs/privacy/index.html`.

Политика внутри приложения (Настройки → Политика конфиденциальности) работает без сети и не зависит от этой страницы.

## Как менять политику

1. Правьте только `Resources/Legal/PrivacyPolicy.ru.md` и `PrivacyPolicy.en.md`. Формат простой: `# ` название, `## ` раздел, `- ` пункт списка одной строкой, остальное абзацы, внутри допустимы `**жирный**` и `[ссылки](https://…)`.
2. Пересоберите страницу: `python docs/build_privacy_page.py`.
3. Обновите дату «Действует с…» в обоих файлах. Если изменилось то, что приложение отправляет наружу, обновите и `app-privacy.md`, и `Resources/PrivacyInfo.xcprivacy`.

## Что остаётся сделать вам

- Проверить приложение на телефоне (сборка в TestFlight) и сделать настоящие скриншоты 1320×2868 или 1290×2796.
- Опубликовать политику и указать её адрес и Support URL.
- Заполнить App Privacy по `app-privacy.md`, возрастной рейтинг, категорию Finance и заметки для проверяющего.
- Добавить описание и ключевые слова на английском и армянском (русское описание есть в папке со скриншотами).
- Решить, нужен ли в политике адрес почты: сейчас связь идёт через ссылку «Поддержка» на странице приложения.
